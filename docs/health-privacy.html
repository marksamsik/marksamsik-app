개인정보처리방침

앱 이름: 마크삼식 헬스 기록 · 패키지: com.marksamsik.health · 개발자: 마크삼식 · 시행일: 2026-10-14

1. 이 앱은 어떤 앱인가요

헬스장 운동(세트·무게·횟수), 식단(칼로리·단백질·탄수화물·지방), 인바디 결과, 바디프로필 준비 체중을 기록하는 앱입니다. 모든 기록은 휴대폰 안에만 저장됩니다.

2. 모으는 정보

  • 운영자가 모으는 개인정보는 없습니다. 회원가입·로그인이 없고, 이름·전화번호·이메일·위치·연락처·기기 고유번호를 모으지 않습니다.
  • 기록을 밖으로 보내지 않습니다. 안드로이드판은 인터넷 권한이 없고, 아이폰판도 기록을 서버로 보내지 않습니다(아이폰판의 음성 인식만 아래 3-1 참고).
  • 휴대폰 안에만 저장되는 것: 운동 기록(운동 이름·기구·무게·횟수·세트·운동 시간), 오운완 기록, 내 헬스장 설정, 식단 기록과 직접 만든 음식, 인바디 기록(체중·골격근량·체지방량·체지방률·BMI·기초대사량·내장지방 레벨·체수분·부위별 근육량 등, 직접 입력하거나 결과지 사진에서 읽은 값), 바디프로필 플랜(성별·나이·키·체중·목표 체중·촬영일·활동량)과 체중 기록, 앱 설정.
  • 이 기록은 사용자가 직접 넣은 것이며, 운영자는 볼 수 없습니다.

3. 사용하는 권한과 기능

  • 마이크(음성 기록): 🎤 버튼을 눌렀을 때만 「벤치 60 10개 3세트」처럼 말한 내용을 글자로 바꾸는 데 씁니다. 음성 인식은 휴대폰에 설치된 음성 인식 서비스(예: Google 음성 인식)가 처리하며, 휴대폰 설정에 따라 그 서비스가 인터넷으로 음성을 처리할 수 있습니다. 앱은 녹음 파일을 저장하지 않습니다.
  • 사진(인바디 결과지·오운완 배경): 사용자가 고르거나 찍은 사진만 씁니다. 결과지 글자 읽기는 앱 안에 들어 있는 글자 인식(Google ML Kit)으로 휴대폰 안에서 처리하며 사진을 밖으로 보내지 않습니다. 카메라 권한을 따로 받지 않고 휴대폰 카메라 앱을 엽니다.
  • 알림·진동·절전 해제: 휴식 시간이 끝났을 때 화면이 꺼져 있어도 진동과 알림으로 알려 주기 위해 사용합니다.
  • 파일 저장·공유: 오운완 이미지 저장(사진 앱 「Pictures/마크삼식 헬스」 폴더), 백업 파일·CSV 저장, 다른 앱으로 공유는 사용자가 버튼을 눌렀을 때만 일어납니다.

인터넷·위치·연락처 권한은 쓰지 않습니다.

3-1. 아이폰판(App Store)에서 다른 점

  • 마이크·음성 인식: 🎤 버튼을 눌렀을 때만 씁니다. 아이폰이 지원하면 음성을 아이폰 안에서 글자로 바꾸고, 지원하지 않거나 실패하면 Apple 음성 인식 서비스가 처리합니다(Apple 개인정보 처리방침 적용). 앱은 녹음 파일을 저장하지 않습니다.
  • 사진·카메라: 결과지 글자 읽기는 아이폰에 들어 있는 글자 인식(Apple Vision)으로 아이폰 안에서 처리합니다. 결과지를 바로 찍을 때만 카메라 권한을 묻고, 오운완 이미지 저장은 사진 앱에 「추가」만 허락받습니다(사진을 읽지 않음).
  • 알림: 휴식 시간이 끝났을 때 다른 앱을 보고 있어도 알려 주는 데만 씁니다.
  • 저장: 기록은 아이폰 안의 앱 저장 공간에만 있고, 아이폰이 저장 공간을 정리할 때를 대비해 같은 기록을 앱 안 파일에도 한 번 더 저장합니다. 백업 파일은 「파일」 앱에서 사용자가 고른 곳에 저장합니다.

4. 이용 목적과 제3자 제공

휴대폰 안에 저장되는 정보는 기록 보기·그래프·지난번 무게 자동 채움·식단 합계·바디프로필 목표 계산에만 쓰입니다. 광고, 분석 도구, 제3자 제공이 없습니다. 사용자가 「공유」를 누른 경우에만 사용자가 고른 앱으로 이미지나 글이 전달됩니다.

5. 건강 정보에 대한 안내

이 앱의 칼로리·체지방률·기초대사량 등은 일반적인 추정 공식과 공개 식품 데이터(농촌진흥청 국가표준식품성분 DB, 식품의약품안전처 식품영양성분 데이터베이스)를 바탕으로 한 참고값이며, 의료 진단이나 치료를 대신하지 않습니다.

6. 삭제 방법

  1. 앱 오른쪽 위 ⚙ 설정 › 「🗑 모든 기록 지우기」를 누르면 운동·식단·인바디·바프 기록이 모두 지워집니다. 기록마다 「이 기록 지우기」로 하나씩 지울 수도 있습니다.
  2. 안드로이드: 휴대폰 설정 › 앱 › 마크삼식 헬스 기록 › 저장공간 › 데이터 삭제를 누르면 모든 정보가 지워집니다. 앱을 삭제해도 모두 지워집니다.
  3. 아이폰: 홈 화면에서 앱을 길게 눌러 「앱 삭제」를 하면 앱 안의 모든 기록이 지워집니다.

운영자 쪽에는 저장된 정보가 없어 따로 삭제 요청을 하실 필요가 없습니다. 사용자가 직접 내보낸 백업 파일은 사용자가 저장한 곳에서 직접 지워 주세요.
