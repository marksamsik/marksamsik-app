1. 이 앱은 어떤 앱인가요

이 앱은 전문스포츠지도사 2급·생활스포츠지도사 2급·유소년스포츠지도사·노인스포츠지도사 실기·구술시험의 구술 연습 앱입니다(축구·태권도·수영·배드민턴·줄넘기·레크리에이션·파크골프·배구·야구·복싱·농구·유도·골프·테니스·탁구·육상·그라운드골프·당구·등산·볼링·빙상·사격·게이트볼·소프트테니스·스쿼시·족구·역도·조정(로잉)·등산(스포츠클라이밍) 29종목, 3,620문항). 문제·모범답안이 모두 앱 안에 들어 있어 인터넷 없이 작동합니다. 모범답안 읽기는 휴대폰에 설치된 음성엔진(텍스트 음성 변환)을 사용합니다.

2. 모으는 정보

  • 모으는 개인정보가 없습니다. 회원가입·로그인이 없고, 이름·전화번호·이메일·위치·연락처·사진·기기 고유번호를 모으지 않습니다.
  • 인터넷 권한이 없습니다. 앱 자체는 인터넷에 연결하지 않으며, 앱이 정보를 밖으로 보내지 않습니다. (단, 🎙️ 음성 채점의 받아쓰기는 아래처럼 휴대폰의 음성 인식 서비스가 처리합니다.)
  • 마이크(🎙️ 음성 채점): 시험장에서 「▶ 시작」을 누른 때부터 「답변 끝」을 누를 때까지만 마이크를 씁니다. 말한 내용을 글자로 바꿔(받아쓰기) 키워드를 자동 채점하고, 원하면 내 답변을 다시 들을 수 있게 녹음합니다. 시험장 입장 화면이나 설정에서 「🎙️ 마이크 자가채점」을 끄면 마이크를 전혀 쓰지 않습니다.
    • 녹음 파일: 휴대폰 안(앱 전용 임시 폴더)에만 잠깐 저장되고, 새 시험장에 들어가면 지워집니다. 앱이 녹음을 다른 곳으로 보내지 않습니다.
    • 받아쓰기: 휴대폰에 들어 있는 음성 인식 기능(안드로이드 기본 음성 인식, 보통 Google 음성 인식)을 사용합니다. 휴대폰 안에서 처리하는 온디바이스 인식을 먼저 쓰고, 휴대폰이 지원하지 않으면 휴대폰의 기본 음성 인식 서비스를 씁니다. 이때 음성 처리는 그 서비스 제공자(Google 등)의 개인정보처리방침을 따릅니다. 받아쓴 글자는 채점 화면에만 쓰이고 저장하거나 전송하지 않습니다.
  • 휴대폰 안에만 저장되는 것: 종목별 문제 연습 결과(😀·😐·😵, 점수), 복습 문제 목록, 설정(목소리·속도 등), 전체 듣기에서 멈춘 위치. 이 정보는 휴대폰 안에만 있고 운영자를 포함해 누구에게도 전송되지 않습니다.

3. 사용하는 권한

  • 마이크(녹음): 🎙️ 음성 채점의 받아쓰기·내 답변 다시 듣기에 사용합니다. 처음 「▶ 시작」을 누를 때 허용 여부를 묻고, 허용하지 않아도 키워드를 직접 체크해 연습할 수 있습니다.
  • 알림: 「전체 듣기」 중 알림창·잠금화면에 재생/멈춤/다음 버튼을 보여 주기 위해 사용합니다.
  • 포그라운드 서비스(미디어 재생)·절전 해제: 화면이 꺼지거나 다른 앱을 쓰는 동안에도 「전체 듣기」가 끊기지 않게 하기 위해 사용합니다.

  1. 앱 오른쪽 위 ⚙ 설정 › 「기록 모두 지우기」를 누르면 연습 기록과 복습 목록이 지워집니다. 복습 목록은 ✕로 하나씩 뺄 수도 있습니다.
  2. 녹음 파일은 새 시험장에 들어갈 때 자동으로 지워집니다.
  3. 휴대폰 설정 › 앱 › 마크삼식 구술 전종목 › 저장공간 › 데이터 삭제를 누르면 모든 정보가 지워집니다. 앱을 삭제해도 모두 지워집니다.
